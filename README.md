Student Management System
Project Description

A beginner-friendly Student Management System developed using Python and SQLite.

Technologies Used
Python
SQLite
SQL
Features
Add Student Details
View All Students
Search Student by ID
Update Student Marks
Delete Student Records
Calculate Average Marks
How to Run
Clone or download this repository.
Open the project folder in VS Code.
Run python database.py.
Run python main.py.
